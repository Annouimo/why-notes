# 如何理解一致连续：制作说明

## 目标与前置知识

读者知道函数、图像与连续的基本定义，希望建立一致连续的图景。读完应能解释统一半宽与逐点选宽的区别，读懂量词顺序，并解释典型反例。交互支持理解，数学理由负责对整个定义域作出结论。

## 已确定的解释主线

1. 认识以 (x₀,f(x₀)) 为中心的框，半高 ε、半宽 δ。
2. 正弦：固定 ε=.5、δ=.4，移动中心，体验同一个框适用不同位置。
3. 抛物线：定义域 ℝ，初始 x₀=1、ε=.5、δ=.1。向右走到失败；只把 δ 减半，当前位置可能修好；继续走又失败。
4. 平方根：最陡处也能统一控制；δ=ε²。后续实现。
5. sin(1/x) 与 x sin(1/x)：对比频率增加与振幅衰减。后续实现。
6. 连接标准定义与图形、量词顺序。
7. 1/x、sin(x²) 作为更多例子。后续实现。

第一轮预览交付站点基础、前两幕和定义衔接。最终讲义仍需完成后续例子后再发布。

## 首轮交互约定

- 左右边绿、上下边红；同时用图例及线型编码，不能只靠颜色。
- δ、ε 分别标注中心到边的距离，总尺寸为 2δ×2ε。
- 直接拖动中心点，左右按钮补充；中心受函数约束。输入框也可指定 x₀。
- 正弦第一幕不开放尺寸调整。
- 平方函数固定 ε，只调整 δ；按钮减半或加倍。
- 主图采用跟随中心的局部视野，坐标显示偏移量，数值显示实际 x₀。平方函数提供可展开的全局定位图。
- 不设只覆盖几个单位的右移上限。数值实现仍有有限精度；控件范围 x₀∈[-10⁹,10⁹]、δ∈[10⁻⁶,.8]，数学公式解释无限范围。
- 收窄后视野随刻度更新并明确提示。首版不做镜头过渡，待体验确认后决定是否增加。
- 图形静止时不持续计算。尺寸观察器调度到下一帧，防止布局反馈循环。
- 状态只评价当前位置；失败反馈给出严格位于左右边界内部的实际反例点。

## 数学约定

- 检查 |x−x₀|<δ 的开区间：角点允许；开区间内部触及红线即失败。
- 只有域内点需要检查。
- sin：用解析极值点和区间端点判断；平方函数用顶点和端点判断，不能依赖采样检测。
- 对正弦统一采用 |sin x−sin y|≤|x−y|。
- 平方差使用 2x₀h+h²，避免大数平方相减的精度损失。
- 一致连续：∀ε>0 ∃δ>0 ∀x₀,x∈D。
- 不一致连续：∃ε₀>0 ∀δ>0 ∃x₀,x∈D，水平差<δ但高度差≥ε₀。

# 交互讲义的阅读约定（试行）

目标是减少理解与操作之间的切换。先用一致连续验证，不为单篇建设通用框架。

- 核心可视化直接嵌入正文；同屏保留一句任务、图像、主要操作、即时反馈。
- 正文保留推理。卡片只带当前观察任务，不重复整段说明。
- 主要操作靠近图像，改变对象与改变视野明确分开。精确输入、视野调整放在辅助菜单。
- 反馈用文字、符号和图中位置共同表达，不只依赖颜色。当前位置满足要求不意味着已证明全局性质。
- 展开探索为可选入口，使用同一图与状态；关闭保留参数、阅读位置和键盘焦点。允许 Escape 退出。
- 不在普通卡片内嵌滚动区。窄屏菜单与展开视图可按需要滚动。
- 空间充足时显示侧边目录；否则使用可展开的小入口，不挤压正文宽度。
- 一次布局试验够用就继续学习；将学习收益作为是否继续修改的依据。

本轮：核心七个例子仍直接可见，不先折叠补充例子。先验证紧凑布局与可选展开是否足以改善阅读，再决定是否需要折叠。

## 固定观察范围与公式线索

- 本篇取消视野移动、局部缩放、找回和任意坐标输入。每个例子明确限定中心与宽度；边界按钮禁用，拖动也遵守同一范围。
- 手机与桌面使用相同的数学范围；线条、文字、触摸热区不随数学范围等比缩小。展开只增加绘图面积，不改变坐标范围。
- 图示展示有限实验，完整定义域的结论靠推导。演示最小宽度不代表数学上不能继续变小。
- 公式补充所用工具和关键关系：常规运算省略，核心转折不省略。前置知识以导数、拉格朗日中值定理和基本代数为准；较长的补充保留折叠入口。
- 本轮以后优先内容与学习，除影响理解或正确性的问题外，不继续打磨单篇布局。

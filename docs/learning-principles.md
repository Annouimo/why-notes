# 学习与讲义制作经验

状态：初稿，待人工审阅。

1. **以学习为目的。** 讲义是检验理解的成果；足以支持理解和操作后，停止界面打磨。
2. **先定解释，再做页面。** 从具体疑问出发，明确前置知识、关键图景和解释顺序；人把关教学意图与数学，AI 协助探索和实现。
3. **让交互服务推理。** 每轮实验围绕一个问题；任务、图像、主要操作和反馈尽量同屏，减少无关功能。
4. **图示与证明各负其责。** 选取足以呈现机制、且小屏可辨认的范围；有限演示不能代替完整结论。
5. **简洁但不断线。** 公式点明所用工具和关键依据，省略机械运算；核心转折与陌生概念讲清楚。
6. **保存可审阅的原稿。** 正文单一来源，构建忠实转换；先预览审阅，再决定发布。出现真实复用需求后再抽象。
7. **用独立表现检验学习。** 关闭讲义后解释、解题，隔一段时间再检验；读得顺畅不等于已经掌握。

维护约定：仅保留经实践检验、可复用的核心经验；新增或改写均须人工确认。优先合并、替换，避免逐次堆积。
